# `projects/skills/`

Owner: every Bot

One folder per Bot role: `projects/skills/<role>/RESOURCES.md` (annotated top-100 list) and `SKILLS.md` (working handbook). Committed on branch `setup/<role>-skills` (tickets M0-SKILL-01..09). Bots re-read their SKILLS.md at every session start and update it when they learn something.
