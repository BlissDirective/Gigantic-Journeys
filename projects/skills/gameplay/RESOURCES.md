# gj-gameplay — Resources (curated foundation)

Curated, verified starter set for movement/character-controller feel and Unity mobile perf. Expand to the full annotated top-100 in a live pass. All entries real/canonical.

## Character controller feel (study these)
- Celeste — Maddy Thorson's movement/physics write-ups (Maddy Makes Games) — coyote time, buffering, dash feel.
- Mario Odyssey / Astro Bot / Super Mario 64 — GDC talks on 3D platformer feel (GDC Vault).
- "Math for Game Programmers: Juicing Your Cameras / Interpolation" (Squirrel Eiserloh, GDC Vault).
- Game Feel — Steve Swink (book) — canonical text on responsiveness.

## Climbing & parkour systems
- Mirror's Edge / Assassin's Creed traversal — GDC Vault talks on parkour/traversal systems.
- Zelda BotW/TotK — GDC talks on climbing, physics, and systemic interaction.
