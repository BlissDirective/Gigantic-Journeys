# gj-avatar — Resources (curated foundation)

Curated, verified starter set. v1 is roster-authoring (no biometric); V2 is custom avatars. Expand to the full annotated top-100 in a live pass. All entries real/canonical.

## v1 roster authoring (open-base, clean IP)
- MakeHuman — makehumancommunity.org (CC0 output) — parametric human base meshes.
- Blender — blender.org (GPL tool; output is yours) — modeling, retarget, bake.
- Mixamo — mixamo.com (Adobe; check license terms) — rigging + clips (contingency path).
- Unity — Humanoid rig / Avatar / Animation Rigging + IK (docs.unity3d.com).
- Character Creator 4 (Reallusion) — reallusion.com — leaner licensed path (needs spend AUTH).

## Mobile character optimization
- Unity — LOD, texture atlasing, mesh compression, baked lighting (docs.unity3d.com; Unity Learn).
- Texture baking (Blender bake / Marmoset) — normal/AO/albedo for mobile.

## V2 — custom avatars (deferred, AUTH #020)

- Auto-rigging (Mixamo auto-rig; RigNet, research) — skeleton fitting.
- Uncanny valley — Mori (1970/2012 IEEE reprint) — foundational reference.
