# services/reconstruction — self-hosted Gaussian-splat pipeline (M1-CAPT-03).
#
# The orchestration (the `reconstruction` package) and its tests are standard
# library only: no third-party runtime dependency, so there is nothing to pin
# here and CI installs nothing. Test tooling (pytest) is provided and pinned by
# CI (.github/workflows/lint.yml).
#
# The heavy GPU tools this pipeline drives — COLMAP/GLOMAP, gsplat/nerfstudio,
# Open3D, splat-transform, torch (CUDA) — are NOT Python-installable in CI and
# live only in the CUDA container image (see Dockerfile), pinned there. Do not
# add them here: CI pip-installs every *requirements*.txt on a CPU runner and
# runs pip-audit against it.
#
# The corpus intake tools (tools/: strip_metadata, corpus_manifest, intake_web) are
# standard library too. They drive ffmpeg/ffprobe and ExifTool, which are system
# packages from the Debian/Ubuntu archives: apt in the Modal intake image
# (corpus_intake_app.py) and in CI (lint.yml). The Operator CLI
# (tools/corpus_intake.py) also needs the `modal` client and `jsonschema`, which are
# already in the Operator VM's .venv.
